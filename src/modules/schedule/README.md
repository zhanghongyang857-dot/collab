# 安排模块（schedule）

主动的规划：今天、这几天打算做什么。给看板加「今天」「短期」两页，标题上方显示"第几周 · 主题"，时钟下面显示正在做什么，「短期」页下半部分放本月布局和本周三件事。

## 数据（NOW 数据目录）

| 文件 | 格式 |
|---|---|
| `安排.md` | 一张表 `| 日期 | 时段 | 事项 | 任务 |`，每件事一行。日期 `MM-DD` 或 `YYYY-MM-DD`；时段写时间（`15:00–16:00`）或时间段名（`上午`），留空是全天，写 `备注` 是当天说明；任务列写 `分类（活动）`，决定颜色，休息写"不计时"。`**…**` 是节点（「短期」顶部出倒计时卡），`*…*` 是虚线块（练习、可选） |
| `归档/YYYY-MM.md` | 过去的行，`archive.py` 按月移入，格式同上 |
| `本月布局.md` | `## 日期范围` 下一句话 + 一张周表（第一列 `第 N 周 MM-DD～DD`，第二列主题，其余列按分类），`## 本周三件事` 下 `1.` `2.` `3.` |
| `今天.md` | 旧版数据，只在没有 `安排.md` 时读 |

文件不存在时对应页面显示空状态。

## 配置（`config.json` 的 `schedule` 一节）

| 字段 | 含义 |
|---|---|
| `plan_slots` | 「短期」里只写时间段名的事项按它排先后，如 `[{"name": "上午", "start": "00:00", "hint": "A 深度"}, …]`；旧配置写在顶层的 `plan_slots` 也认 |

## 对外

- `provides: plan`：解析好的安排 `{exists, slots, items: [{date, year, when, start, end, what, kind, task, cat}]}`；`items` 含 `归档/` 里的过去月份（年份取文件名），「今天」「短期」页面自己只用 `安排.md` 的行。
- 开放挂点 `today.side`（右栏，如截止模块）、`today.top`（时间轴上面）和 `schedule.timeline.lanes`（时间轴每一段的附加轨道，如对照模块的实际轨道；安排以外的时段有内容时多画一行"安排以外"）。

## archive.py

```bash
python3 modules/schedule/archive.py --now-dir <NOW 目录>   # 加 --dry-run 只预览，--before YYYY-MM-DD 指定日期
```

把日期早于今天的行移到 `归档/YYYY-MM.md`，收工时运行。旧路径 `board/now/archive.py` 仍可用。
