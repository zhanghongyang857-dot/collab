# 日历模块（calendar）

English: [README.en.md](README.en.md)

NOW 看板的「日历」页：按月的网格（周一开头）和日期待定栏。只读，新事件用口令「记事件：…」写进文件。

日历放**事件**（外面存在的、可以去也可以不去的事：讲座、课、宣讲会），和安排（承诺要做的事）在数据上不关联：事件不会自动变成安排，安排也不回写日历。唯一的交集是口令「排明天」里的参考步骤，排不排由本人决定。

## 页面

- 顶部「2026 年 11 月」，右边「上一月、今天、下一月」；默认本月，页面自动刷新时停在正在看的月份，可翻到已过去的月。
- 周一开头的 7 列网格，只铺这个月需要的周数，每格等高；非本月的日期淡化，周末略深，今天的日期是红色圆底。
- 格子里一个事件一条：左侧分类色条、标题单行截断、有开始时间写在标题前；重要的加粗，暂定的虚线框，全天的浅色底，没配 `major_category` 时考核项带「考核」标记，配了则和重大事项类同色同样式、不再单独标记。
- 每格最多 3 条，多出的写「还有 N 项」；点某一天（或「还有 N 项」）弹出当天详情（时间、标题、地点、备注），点关闭、空白处或按 Esc 关掉。
- 多天事件在覆盖的每一天都显示。
- 月历右边一栏（约 160px）是分类说明：每类一行，色块、名称、说明（note）、当前显示月份的条数（多天事件算一次，只算和这个月有重叠的事件；待定的不算）。点一类只看这一类（月历、待定栏和当天详情都只留这一类，条数不变），再点取消；选中有底色和左色条；翻月和自动刷新时筛选保留。窄于 900px 时说明栏移到月历下方。
- 分类列不在配置列表里（含空）的事件显示为灰色「未分类」，说明栏多这一行并写条数，不会被悄悄丢掉。没配 `categories` 时说明栏按实际出现的分类显示，没有说明。
- 窄屏（≤760px）事件条缩成色点，页面不横向溢出。
- 网格下面是「日期待定」栏；看不懂的行在页面底部提示。

## 数据

`日历/日历.md`（相对 NOW 数据目录），一张表，每个事件一行，按日期升序：

```
| 日期 | 时间 | 事件 | 分类 | 地点 | 备注 |
|---|---|---|---|---|---|
| 2026-11-10 | 18:30–21:20 | 示例课程 · 体系结构 | 课程 | 示例教学楼 101 | |
```

| 列 | 写法 |
|---|---|
| 日期 | `YYYY-MM-DD`；多天 `2026-12-01～12-03`，跨年 `2026-12-30～01-02`（结束的月日早于开始就算下一年）；日期未定写 `待定` |
| 时间 | `HH:MM–HH:MM`、只写开始 `HH:MM`，留空为全天 |
| 事件 | 一句话；整句包在 `**…**` 里表示重要 |
| 分类 | 取 `calendar.categories` 里的名称（精确匹配）；不在列表里或留空显示为「未分类」 |
| 地点、备注 | 可空；备注含“大致”“待公告”“暂定”“待定”时显示为虚线框 |

日期或时间写错的行会跳过，页面底部列出来，不影响其他行。文件不存在时显示空状态。

**考试和截止不写在日历里。** 装了截止模块（`uses: deadlines`）时，页面通过 `ctx.get("deadlines")` 取它解析的文件，合并显示，只记一份（配了 `major_category` 时归入那一类，详情里写来源「考核安排」或「日历」，否则标“考核”）；没装就只显示日历文件里的事件。合并的范围就是截止模块自己配置的范围（`deadlines.groups`）。

## 配置（`config.json` 的 `calendar` 一节，都可以不写）

| 字段 | 含义 |
|---|---|
| `categories` | `[{name, keywords, color, note}]`，`color` 同核心可选色（含 `yellow`），`note` 是一句说明，显示在右侧说明栏。日历文件的分类列按 `name` 精确匹配；没配时沿用核心的分类和颜色，页面照常运行 |
| `major_category` | 字符串，指定 `categories` 里哪一类是重大事项（须与某个 `name` 一致）。考核项归入这一类，和文件里标了这一类的事件同色，只出现一次，仍不写进日历文件。没配或不在列表里时，考核项按名字对 `keywords` 匹配并保留“考核”标记 |
| `file` | 日历文件，默认 `日历/日历.md` |
| `tentative_keywords` | 备注含这些词就画虚线框，默认 大致、待公告、暂定、待定 |

## 对外

`provides: events`：日历文件里有日期的事件 `[{date, end, start, endTime, allDay, title, important, place, note, category, cat, catKey, tentative, exam, source}]`（不含考核项，考核项在截止模块的 `deadlines`）。

## 口令

`口令.md`：**记事件：…**（追加一行并回报）；**排明天** 的参考步骤：列出明天及之后 3 天的日历和截止事件。合并后的位置由 `config.json` 的 `modules` 顺序决定：写在 `schedule` 之后，这一步就接在安排的排明天后面，所以措辞是“写明天的行时参考”，前后位置都读得通。

## 配置示例（虚构）

```json
"calendar": {
  "categories": [
    {"name": "重要", "color": "red", "note": "不能错过的事，含考核"},
    {"name": "学习", "color": "blue", "note": "课程、讲座"},
    {"name": "休闲", "color": "yellow", "note": "私人时间"}
  ],
  "major_category": "重要"
}
```
